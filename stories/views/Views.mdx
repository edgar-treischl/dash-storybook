# Views Overview

Views are complete page layouts that combine multiple UI components, data management, and layout patterns. They demonstrate how to build production-ready pages using reusable components from the `@edgar-treischl/dash-ui` library.

## What is a View?

A **View** is a complete, self-contained page layout that:

- ✅ Combines multiple components (charts, controls, statistics)
- ✅ Manages state and data flow
- ✅ Implements responsive layouts
- ✅ Demonstrates best practices for structuring pages
- ✅ Serves as a reference for building new pages in your applications

## Building a New View

### Step 1: Plan the Layout
```
- Identify main sections (header, chart, sidebar, footer)
- Decide on responsiveness breakpoints
- Consider data flow and state management
```

### Step 2: Create the Component
```typescript
// views/YourView.stories.tsx
import { Meta, StoryObj } from '@storybook/react'

function YourViewComponent() {
  const [state, setState] = useState(...)
  
  return (
    <div className="your-view">
      <section className="your-view__main">
        {/* Your content */}
      </section>
    </div>
  )
}

const meta: Meta<typeof YourViewComponent> = {
  title: 'Views/Your View Name',
  component: YourViewComponent,
  parameters: { layout: 'fullscreen' }
}

export default meta
type Story = StoryObj<typeof meta>

export const Default: Story = {}
```

### Step 3: Add Styling
```typescript
// views/YourView.css
```

### Step 4: Integrate Components
```typescript

```

## Styling Best Practices

### Color Coding
- Use consistent color schemes across all views
- Define color constants for school types, status indicators, etc.
- Example: `SCHOOL_TYPE_COLORS = { GS: '#FF6B6B', MS: '#4ECDC4', ... }`

### Responsive Design
- Mobile-first approach
- Use CSS Grid and Flexbox
- Test breakpoints: 640px, 1024px, 1280px+

### Spacing and Layout
- Use consistent rem-based spacing (0.5rem, 1rem, 1.5rem, 2rem)
- Maintain visual hierarchy with typography and spacing
- Card-based layouts for grouped content

## Performance Tips

✨ **Memoization** - Use `React.memo()` for view components to prevent unnecessary re-renders

✨ **Lazy Loading** - Load heavy data visualizations only when visible

✨ **Type Safety** - Define clear types for all data structures

✨ **Responsive Images** - Use CSS Grid and Flexbox instead of fixed widths
